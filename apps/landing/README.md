# SocketLens Landing Page

This workspace contains the SocketLens marketing landing page.

## Stack

- React
- Vite
- TypeScript
- TailwindCSS

## Run Locally

From the repository root:

```bash
npm run dev:landing
```

Or from this workspace:

```bash
npm run dev --workspace @socketlens/landing
```

The dev server runs at:

```text
http://127.0.0.1:5175
```

## Build

From the repository root:

```bash
npm run build:landing
```

The production output is written to `apps/landing/dist`.
