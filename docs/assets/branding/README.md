# Branding Assets

Temporary SocketLens branding assets for the public alpha repository.

These assets are original placeholder artwork. Replace them with final brand assets before a stable public release, but keep the same filenames so README and release references do not break.

## Canonical Files

- `logo.svg`: light-surface horizontal logo.
- `logo-dark.svg`: dark-surface horizontal logo.
- `logo-mark.svg`: square mark for avatars, favicons, and app icons.
- `icon.png`: temporary PNG app/launcher icon.
- `icon.ico`: temporary Windows shortcut icon.
- `banner.png`: README/GitHub banner placeholder.

## Legacy Files

These are kept for compatibility with earlier docs and release materials:

- `socketlens-app-icon.svg`
- `socketlens-wordmark.svg`
- `socketlens-banner.svg`

## Usage Rules

- Keep the dark developer-tool aesthetic.
- Do not use third-party or copyrighted artwork.
- Do not imply a stable commercial release; SocketLens is `v0.1.0-alpha`.
- Regenerate platform installer icons from `logo-mark.svg` before a signed release.
- Update all README and release references when replacing assets.
