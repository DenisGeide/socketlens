# Diagrams

Purpose: reserve a stable location for exported architecture diagrams and visual documentation assets.

Most SocketLens architecture diagrams currently live directly in Markdown as Mermaid blocks, especially in [Architecture](../../architecture.md). Exported PNG/SVG diagrams can be placed here later when needed for GitHub, releases, or presentations.

## Recommended Naming

- `architecture-overview.png`
- `packet-flow.png`
- `proxy-flow.png`
- `decoder-pipeline.png`
- `session-export-flow.png`

## Rules

- Do not add diagrams that describe planned features as implemented.
- Prefer Mermaid in docs when the diagram is simple and maintainable.
- Use exported images only when they improve readability.
- Keep filenames stable after README/docs start referencing them.
